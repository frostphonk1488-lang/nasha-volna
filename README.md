# Nasha Volna AI

Статический MVP. `index.html` загружает `task-core.js` и `app.js`; данные и контекст
диалога сохраняются в `localStorage` под прежним ключом `nv_mvp_v2`.
Сервер, синхронизация между устройствами и языковая модель пока не подключены.
Python-пакет `core/` — отдельный прототип, он не исполняется на GitHub Pages.

## Задачи через чат

1. `Создай задачу: Проверить MVP на завтра`
2. `Переименуй её в Проверить отчёт`
3. `Перенеси её на 30.09.2026`
4. `Покажи задачи`
5. `Заверши её`

Также: `Возьми в работу задачу Проверить отчёт`, `Возобнови её`,
`Найди задачу отчёт`, `Покажи активные задачи`, `Покажи выполненные задачи`.
«Её» относится к последней созданной, выбранной или изменённой задаче.
Если совпадений несколько, укажите номер из предложенного списка или точное
название. `Отмена` отменяет ожидающее уточнение, но не откатывает уже выполненные действия.
Если команда создания не содержит названия, ядро спрашивает его следующим сообщением.

Сроки: сегодня/завтра/послезавтра (по Москве), ДД.ММ.ГГГГ или ГГГГ-ММ-ДД.
Название активной задачи проверяется на дубликат. Произвольный разговор и сложные
составные поручения не поддерживаются: это локальный обработчик команд, не LLM.
Данные сохраняются только в этом браузере; очистка данных сайта удаляет их.
При ошибке записи команды чата откатываются и показывают ошибку вместо успеха.

## Проверка

```sh
node --test tests/*.test.cjs
python -m unittest discover -s core/tests
python -m http.server 8765
```

Откройте http://localhost:8765. После создания/изменения задачи обновите страницу
и проверьте раздел «Задачи». На телефоне разделы доступны в горизонтальном меню.
