# МойБизнес — мини-ERP

В репозиторий добавлена страница `1c.html` — браузерный прототип системы учёта в стиле классических решений 1С.

Разделы:
- Главная и сводные показатели
- Продажи
- Покупки
- Склад
- Контрагенты
- Касса
- Отчёты

Данные демо-приложения сохраняются в localStorage браузера. Это прототип интерфейса, а не полноценная бухгалтерская система и не заменяет 1С.
