# AI-помощник «Наша волна»

В репозитории добавлен полноценный интерфейс AI-помощника с локальной памятью и серверным API.

## Как работает
- `ai.html` — интерфейс чата.
- `api/chat.js` — защищённый серверный endpoint для OpenAI API.
- История и память дополнительно сохраняются в `localStorage`.
- API-ключ **не хранится в HTML/JS**.

## Деплой
GitHub Pages умеет отдавать статический HTML, но не запускает `api/chat.js`. Поэтому для настоящего AI нужен Vercel/другой серверless-хостинг.

В Vercel:
1. Импортировать этот GitHub-репозиторий.
2. Добавить переменную окружения `OPENAI_API_KEY`.
3. При необходимости задать `OPENAI_MODEL`.
4. Открыть `/ai.html`.

После этого интерфейс будет обращаться к `/api/chat`.

Для продакшена стоит добавить авторизацию, лимиты запросов и серверную БД для памяти, если память должна быть общей между устройствами.
