# NVC Intent Router v0.1

Router превращает естественный запрос в структурированное намерение.

Пример:

Пользователь:
"Создай задачу Анне подготовить договор до пятницы"

Результат:

```json
{
  "intent": "create_task",
  "entities": {
    "assignee": "Анна",
    "title": "подготовить договор",
    "deadline": "пятница"
  }
}
```

Router не выполняет действие сам. Он передаёт намерение следующему слою Core.
