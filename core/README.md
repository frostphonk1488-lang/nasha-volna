# Nasha Volna Core

Nasha Volna Core (NVC) — собственное AI-ядро платформы.

## Цель v0.1

Запрос пользователя проходит через:

1. Intent Router — определение намерения.
2. Memory — получение релевантной памяти.
3. Context Builder — сбор контекста.
4. Tool Registry — выбор разрешённого действия.
5. Executor — выполнение действия.
6. Memory Writer — сохранение результата.

AI-модель является сменным компонентом. Core не привязан к одному поставщику модели.

## Принцип

**Модель отвечает. Core понимает контекст, управляет памятью, инструментами и безопасностью.**

Текущая версия — архитектурный каркас. Реальный backend подключается следующим этапом.
